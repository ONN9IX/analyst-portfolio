# A/B-тест Cookie Cats: влияние положения gate на retention

## Задача
В мобильной игре Cookie Cats первый gate был перенесён с уровня 30 на уровень 40. Цель анализа — проверить, изменилось ли удержание игроков после переноса.

**Контроль:** `gate_30`  
**Тест:** `gate_40`

## Данные
Используется публичный датасет Cookie Cats: 90 189 игроков и 5 полей:
`userid`, `version`, `sum_gamerounds`, `retention_1`, `retention_7`.

Источник: Kaggle, *Mobile Games A/B Testing — Cookie Cats*. Датасет не генерируется и не подменяется синтетическими данными.

## Метрики
- 1-day retention;
- 7-day retention;
- число игровых раундов;
- абсолютная разница retention в процентных пунктах;
- 95% доверительный интервал.

## Методология
1. Проверка размера выборки, пропусков и уникальности `userid`.
2. Проверка распределения пользователей между вариантами.
3. Сравнение retention.
4. Chi-square test для бинарных retention-метрик.
5. Доверительный интервал разницы долей.
6. Bootstrap как дополнительная проверка устойчивости результата.
7. Анализ `sum_gamerounds` с учётом сильной асимметрии распределения.

Уровень значимости: **α = 0.05**.

## Гипотезы
**H0:** retention в `gate_30` и `gate_40` одинаков.  
**H1:** retention между вариантами различается.

## Воспроизводимость
Поместите исходный файл в `data/cookie_cats.csv`, затем запустите:

```bash
pip install -r requirements.txt
python analysis.py
```

Скрипт рассчитывает показатели из исходных данных; результаты не зашиты вручную.

## Ограничения
Retention — показатель вовлечённости, а не прямой показатель выручки. В датасете нет данных о покупках, стоимости изменения или пользовательских сегментах, поэтому бизнес-решение нельзя интерпретировать как оценку финансового эффекта.
