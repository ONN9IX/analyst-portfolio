# Источник данных

Файл: `global_ecommerce_sales.csv`

В репозитории хранится фактически используемая копия CSV. Данные содержат **2 000 заказов** за период **2023-01-02 — 2025-12-31**.

Поля источника включают Order_ID, Order_Date, Customer_Name, Customer_Segment, Country, Region, Product_Category, Product_Name, Quantity, Unit_Price, Discount_Percent, Total_Sales, Shipping_Cost, Profit и Payment_Method.

## Важно
Набор используется как публичный учебный/портфельный источник и не представляется как внутренняя выгрузка конкретной компании. Revenue в анализе рассчитывается по `Total_Sales`, поскольку это поле учитывает скидки источника.
