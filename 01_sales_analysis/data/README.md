# Данные о продажах

Файл: `global_ecommerce_sales.csv`. В нём 2 000 записей, 15 столбцов и даты заказов с 02.01.2023 по 31.12.2025.

Это **учебный набор e-commerce транзакций**, а не подтверждённая выгрузка из действующего интернет-магазина. Сходный публичный источник с тем же названием и объёмом файла размещён на [Kaggle — Global E-Commerce Sales & Customer Data](https://www.kaggle.com/code/muhammadaammartufail/global-e-commerce-sales-customer-analytics/input). Точный первоначальный автор и цепочка получения этой копии CSV в репозитории не задокументированы.

В анализе выручка берётся из `Total_Sales`: поле уже учитывает скидки. `Customer_Name` заменяет отсутствующий `Customer_ID`, поэтому количество уникальных покупателей — только оценка по именам.

**Назначение данных:** практика проверок качества, расчёта KPI, SQL-запросов и BI. Полученные суммы относятся только к этому датасету, а не к результатам реальной компании.
