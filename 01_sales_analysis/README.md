# Анализ продаж — E-commerce 2023+

## Цель
Провести воспроизводимый анализ современных продаж и показать навыки Python/Pandas, EDA и бизнес-аналитики.

## Стандарт данных
Используются только наблюдения **с 2023 года**. Предыдущий Superstore с данными 2014–2017 удалён из проекта.

## Требуемая схема
Минимальные поля:
- `order_id`
- `order_date`
- `customer_id`
- `product_name`
- `category`
- `quantity`
- `revenue`

Дополнительно приветствуются `profit`, `discount`, `region`, `segment`.

## Анализ
1. Проверка типов, пропусков и дубликатов.
2. Фильтрация периода 2023+.
3. Revenue, Orders, Customers, Units, AOV.
4. Месячная динамика.
5. Категории и товары.
6. Клиенты и регионы при наличии соответствующих полей.
7. Выводы только после фактического расчёта.

## Запуск
```bash
pip install -r requirements.txt
python analysis.py
```

Файл данных: `data/sales_data.csv`.

## Принцип
Проект не содержит выдуманных KPI или заранее написанных «успешных» выводов. Скрипт проверяет схему и период и завершится с ошибкой, если данные не соответствуют требованиям.
