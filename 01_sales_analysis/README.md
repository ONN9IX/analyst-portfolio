# Анализ продаж — Global E-Commerce 2023–2025

## Данные
В репозитории находится валидированный `global_ecommerce_sales.csv`: **2 000 заказов** за период **02.01.2023–31.12.2025**.

Поля включают дату, клиента, сегмент, страну/регион, категорию, товар, количество, цену, скидку, Total Sales, доставку, Profit и способ оплаты.

## Методика
Revenue берётся из исходного `Total_Sales`, поскольку набор уже учитывает скидку. Использование простого `Quantity × Unit_Price` завысило бы продажи для строк со скидкой — эта ошибка устранена при QA.
