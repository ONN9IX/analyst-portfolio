# Данные проекта 03

Для проекта используется современный e-commerce набор с периодом **2023–2024** и отдельными сущностями клиентов, товаров, заказов и позиций заказов.

Старый Brazilian E-Commerce by Olist (2016–2018) удалён из плана, поскольку он не соответствует требованию по свежести данных.

При выборе финального источника обязательны:
1. даты операций от 2023 года;
2. идентификаторы заказов и клиентов;
3. товары/категории;
4. сумма или цена × количество;
5. возможность выполнять JOIN и оконные функции.

Если источник является синтетическим/учебным, это должно быть явно указано в README — выдавать такие данные за реальные транзакции нельзя.
