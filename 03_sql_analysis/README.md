# SQL-анализ Brazilian E-Commerce by Olist

## Цель
Показать практическое владение SQL на реляционных данных реального e-commerce: продажи, клиенты, товары и динамика бизнеса.

## Датасет
**Brazilian E-Commerce Public Dataset by Olist** — анонимизированные коммерческие данные примерно о 100 тыс. заказов за 2016–2018 годы.

В анализе используются таблицы заказов, позиций заказа, клиентов, товаров и перевод категорий.

## Бизнес-вопросы
- Какова выручка и количество доставленных заказов?
- Как меняются продажи по месяцам?
- Какие категории формируют выручку?
- Какие клиенты покупают повторно?
- Какие клиенты дают выручку выше среднего?
- Как меняется выручка месяц к месяцу?
- Как выглядит накопительная выручка?

## SQL-навыки
`JOIN`, `GROUP BY`, `CASE`, `CTE`, подзапросы, `LAG`, оконные функции, агрегаты, работа с датами.

## Важная особенность данных
В Olist поле `customer_id` связано с конкретным заказом. Для анализа одного и того же покупателя между заказами используется `customer_unique_id`. Это учитывается в запросах проекта.

## Принцип расчётов
Основные показатели продаж считаются по заказам со статусом `delivered`. Product revenue рассчитывается по `order_items.price`; стоимость доставки анализируется отдельно и не смешивается с выручкой от товаров.

## Ограничения
Данные относятся к 2016–2018 годам и используются как портфельный аналитический кейс, а не как описание текущего состояния Olist.
