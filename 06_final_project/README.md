# E-commerce 360 — итоговый проект Data Analyst

## Цель
Итоговый end-to-end кейс, объединяющий SQL, Python, статистический подход, бизнес-метрики и Power BI.

## Данные
Основной период — **2023+**. Используются только поля, реально присутствующие в выбранном источнике.

## Pipeline
```text
Raw data → Data quality → SQL → Python EDA → Business metrics → Dashboard → Insights
```

## Аналитические блоки
- продажи: Revenue, Orders, AOV, MoM;
- клиенты: repeat rate, RFM/cohorts при достаточной истории;
- товары: категории, товары, маржинальность при наличии cost;
- маркетинг: CAC/ROAS/ROI только при наличии spend/acquisition data;
- статистика: только при корректной постановке и подходящих данных;
- dashboard: Overview, Sales, Products, Customers.

## Контроль качества
- никаких синтетических данных без явной маркировки;
- никаких выдуманных KPI;
- никаких рекомендаций до расчёта результатов;
- проверка периода и схемы;
- разделение фактов, интерпретаций и ограничений.

Подробный план находится в `PROJECT_SPEC.md`.

## Статус
Архитектура проекта готова. Финальные численные результаты и визуализации добавляются только после валидации выбранного 2023+ датасета.
