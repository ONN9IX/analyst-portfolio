# Relational SQL Business Case

## Цель
Показать работу с нормализованной PostgreSQL-моделью, где аналитика требует реальных JOIN между сущностями, а не искусственного разделения одного CSV.

## Модель
- `customers` — клиенты и сегменты;
- `products` — товары и категории;
- `orders` — заказы;
- `order_items` — состав заказов;
- `payments` — оплаты.

Данные в `01_seed.sql` — небольшой учебный набор для воспроизводимого запуска SQL-запросов. Это не реальные транзакции.

## Бизнес-вопросы
1. Какая выручка и число заказов по месяцам?
2. Какие категории формируют выручку и валовую прибыль?
3. Какие клиенты являются повторными?
4. Как распределяются клиенты по value-сегментам?
5. Какие товары лидируют внутри своих категорий?
6. Как меняется месячная выручка MoM?
7. Как распределяется выручка по способам оплаты?

## Что демонстрирует
`INNER JOIN`, `LEFT JOIN`, `CASE`, CTE, correlated aggregation, `LAG`, `DENSE_RANK`, cumulative `SUM OVER`, `NULLIF`.

## Запуск
```bash
psql -d your_database -f sql/00_schema.sql
psql -d your_database -f sql/01_seed.sql
psql -d your_database -f sql/02_business_analysis.sql
```
