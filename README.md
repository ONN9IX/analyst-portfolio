# Портфолио Data Analyst

Привет! Я начинающий аналитик данных, развивающий навыки
анализа данных, SQL, Python, статистики и визуализации.

В этом репозитории собраны мои учебные и практические проекты,
демонстрирующие навыки работы с данными и решения бизнес-задач.

## Навыки

- Анализ данных
- Очистка и подготовка данных
- Исследовательский анализ данных (EDA)
- SQL
- Python
- Статистика
- A/B-тестирование
- Визуализация данных
- Бизнес-аналитика

## Проекты

### 1. Анализ продаж

Анализ данных интернет-магазина для изучения динамики продаж,
наиболее прибыльных товаров, категорий и поведения клиентов.

**Инструменты:** Python, Pandas, Matplotlib

[Посмотреть проект](./01_sales_analysis/)

---

### 2. A/B-тестирование

Анализ результатов A/B-теста для определения эффективности
изменения на сайте и влияния нововведения на конверсию.

**Инструменты:** Python, Pandas, SciPy, статистика

[Посмотреть проект](./02_ab_testing/)

---

### 3. Анализ интернет-магазина с помощью SQL

Анализ базы данных интернет-магазина с использованием SQL
для ответа на ключевые бизнес-вопросы.

**Инструменты:** SQL, PostgreSQL

[Посмотреть проект](./03_sql_analysis/)

---

### 4. Анализ маркетинговых кампаний

Анализ эффективности рекламных каналов и кампаний.

Рассматриваемые показатели:

- CAC
- LTV
- ROI
- конверсия
- удержание клиентов

**Инструменты:** Python, Pandas, SQL

[Посмотреть проект](./04_marketing_analysis/)

---

### 5. Дашборд продаж

Интерактивный дашборд для анализа основных показателей
интернет-магазина.

На дашборде представлены:

- выручка;
- количество заказов;
- средний чек;
- динамика продаж;
- продажи по категориям;
- лучшие товары;
- регионы.

**Инструменты:** Power BI

[Посмотреть проект](./05_dashboard/)

---

### 6. Итоговый проект

Комплексный проект по анализу данных интернет-магазина.

В рамках проекта выполнен полный цикл работы:

**Получение данных → Очистка → SQL-анализ → Исследовательский анализ → Статистический анализ → Визуализация → Бизнес-рекомендации**

**Инструменты:** Python, SQL, PostgreSQL, Pandas, Power BI

[Посмотреть проект](./06_final_project/)
