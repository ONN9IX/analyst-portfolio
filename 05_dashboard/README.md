# Power BI Sales Dashboard — 2023+

## Цель
Интерактивный BI-проект на современных e-commerce данных.

## Страницы
**Overview:** Revenue, Orders, Customers, AOV, Profit (если доступен).  
**Sales:** месячная динамика, категории, регионы.  
**Products:** топ товаров, категории, маржинальность при наличии себестоимости/прибыли.  
**Customers:** сегменты и повторные покупки при наличии истории.

## Файлы
- `DASHBOARD_SPEC.md` — точная структура страниц;
- `measures.dax` — DAX-меры.

## Период
Источник должен содержать данные **2023 года и новее**.

## Важное ограничение
Файл `.pbix` и screenshots не заявляются как готовые, пока они реально не собраны в Power BI Desktop. В репозитории не создаются фиктивные бинарные файлы.
